BRG(1)borgchart manualBRG(1)

NAME

brg, borgchart - run teams of coding agents from plain files

SYNOPSIS

brg <COMMAND> [OPTIONS]

DESCRIPTION

Describe each role's model and standing task in a team folder, then brg create <team> <folder> starts an instance of it working in that folder. brg status shows who is alive, what they are doing and their unread message counts; brg attach drops you into a member's live session; brg stop stops it all, and brg start brings it back.

Members are claude and codex sessions on a private tmux server. They talk over a message bus of durable plain messages and acknowledgements, and a team can be a member of another team.

Early, and expected to change.

QUICK START

$ cargo install --git https://github.com/mrshll/borgchart --locked borgchart
$ brg validate ./lamp-eng
$ brg create ./lamp-eng ~/src/lighthouse
$ brg status -w
$ brg attach lamp-eng-x7k2/lead-q8m3
$ brg stop lamp-eng-x7k2

Needs Rust 1.89 or newer, tmux 3.2 or newer, and the claude and/or codex CLIs.

COMMANDS

Team folders

ls
List the teams in the search paths, each with its instances
validate
Check a team folder and brg's configuration; starts nothing
secret
List the secrets a team's plugins need, and whether each is set

Instances and members

create
Make an instance of a team, or a member of a role
start
Bring an instance to what should be running, or start one member
stop
Stop an instance and all its copies deepest first, or one member
delete
Remove a stopped instance, or a stopped member
status
Show an instance tree, or every top-level one, with nested copies
attach
Open a member's live session (detach with your tmux prefix, then d)
logs
Show a member's or plugin's recent output

Messages

send
Store a message for its recipient, and type it in when safe
inbox
List the unacknowledged messages addressed to you, oldest first
msg
Read and acknowledge bus records
bus
Check the tree's message storage

Cleanup

cleanup
Remove what brg left behind for deleted members and copies
reset
Stop a whole tree and forget it, so brg create can start it fresh

brg help <command> or brg <command> --help gives a command's details.
